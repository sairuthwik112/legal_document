# AI-Powered Legal Document Review System (Capstone Project)

This repository implements an AI-powered legal document review system built
on Microsoft Foundry, using three Foundry Agents (Document Ingestion, Clause
Extraction, Compliance Validation), a RAG knowledge base backed by Azure AI
Search, and a simple Streamlit interface.

> **Disclaimer:** This is an AI-assisted preliminary document review system.
> Final legal decisions must be made by an authorized legal professional.
> All sample documents are synthetic and created only for educational
> demonstration purposes.

## Project Status

Implemented so far: **Phase 1 — project folders and synthetic sample
documents.** Later phases (Foundry setup, Blob Storage, Azure AI Search/RAG,
agents, orchestration, human-review checkpoints, Streamlit UI, evaluation)
have not been started yet and will be added incrementally.


## Sample Data

All sample documents are generated by
[`scripts/generate_sample_documents.py`](scripts/generate_sample_documents.py)
and are clearly stamped with:

> "Synthetic educational document created for project demonstration."

**Contract to review** (`data/contracts/`):
- `sample-vendor-agreement.pdf` — a fictional vendor services agreement.
  It intentionally includes a vague Data Privacy clause and omits
  Information Security, Intellectual Property, and Dispute Resolution
  clauses, so later phases have realistic "missing" and "incomplete" clause
  scenarios to detect.

**Knowledge-base documents** (`data/knowledge_base/`):
- `vendor-contract-policy.pdf` — required clauses for vendor contracts.
- `data-privacy-requirements.pdf` — minimum data privacy contract language.
- `information-security-policy.pdf` — required security controls/clauses.
- `legal-compliance-guidelines.pdf` — governing law, dispute resolution,
  and risk-rating guidance.
- `approved-contract-template.pdf` — sample acceptable clause language.

To regenerate the sample PDFs:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python scripts\generate_sample_documents.py
```
